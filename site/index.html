Checkout test suite

Risk-based Playwright tests for the checkout flow of saucedemo.com, a public demo shop. 15 tests on Chromium, run in GitHub Actions on every pull request and push to main.

Open the latest test report →

Test strategy

  • Scope: checkout only, from login and adding to the cart through to the order confirmation.
  • Risk-based: each spec covers one checkout risk with the test design technique that suits it.
  • Characterization tests: saucedemo specifies no rules for names or zip codes, so the tests record what the site does today instead of guessing a rule.
  • Known defects: tests that check behaviour the site gets wrong are marked test.fail. They pass while the defect exists, so the suite stays green.

Reading the report

The two known-defect tests appear with ✘ but count as passed, because test.fail expects them to fail. Any other ✘ is a real failure. If a known-defect test turns red with Expected to fail, but passed, the site has fixed that defect.
